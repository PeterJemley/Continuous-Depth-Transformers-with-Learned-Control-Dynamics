# N17 calibration run

Generated by `n17_analyze.py` from the records in `n17_calib/`, with N12's `n80` records in `n12_calib/`, N13's `n80-rw` records in `n13_calib/`, N14's training records in `n14_calib/` and the saved `rw-oracle`'s training records in `n15_calib/`. Preregistration: `N17_PREREGISTRATION.md`.
Measured on the held-out tail's windows [513, 1024], N12's. Δ_A is head B's clean-target loss minus head A's; x the judge's accuracy, its clean-target loss minus head A's (head C's in a new arm, x_self = Δ_A(rw-b1), 0 for rw-oracle); G = Δ_A(rw-b1) − Δ_A(sub20) the shortfall; F = (Δ_A(rw-b1) − Δ_A(arm)) / G the recovered fraction; F_lf the loop-free line through the rungs' (x, F); F* = F_lf(x_self); d = F(rw-peer) − F_lf(x_peer). The two claims' intervals are Bonferroni-corrected t-intervals at 97.5%; every other interval is a 95% t-interval and decides nothing.

This is the calibration run of the preregistration's calibration step: one seed, on windows the real run does not use. It decides nothing but which loop-free rungs the real run trains, and no verdict is computed. `rw-oracle` is N15's calibration model of the same seed, re-measured.
